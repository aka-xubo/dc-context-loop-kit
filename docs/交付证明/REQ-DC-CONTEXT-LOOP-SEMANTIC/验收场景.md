# 验收场景

## 当前说明

以下场景与验收矩阵共同构成已确认的完整 SPEC。

```yaml
document_type: acceptance_scenarios
requirement_ref:
  requirement_id: REQ-DC-CONTEXT-LOOP-SEMANTIC
acceptance_scenarios:
  status: CONFIRMED
  scenarios:
    - id: SCN-001
      title: 基于完整历史形成上下文理解
      business_result: 模型能够从 Issue 原始评论、本地相关材料和用户最新消息形成可审阅的当前上下文理解。
      given:
        - Issue 包含普通讨论、结构化事件和用户最新指令
        - 本地技能包包含与 Issue 相关的代码、文档和测试材料
      when: 继续处理该 Issue
      then:
        - id: THEN-001
          statement: 输出区分已确认事实、普通讨论、用户指令、当前适用定义、冲突和未决问题
        - id: THEN-002
          statement: 输出引用 Issue 评论、本地材料或用户指令作为判断依据
      delivery_surfaces: [skill]
    - id: SCN-002
      title: 选择当前交付节点和下一步
      business_result: 模型能够根据上下文区分业务承诺变化、验收定义变化和实现变化，并选择一个最小可执行下一步。
      given:
        - 当前上下文包含至少一个需求、规格、实现或验收事实
      when: 用户提出继续处理或新增反馈
      then:
        - id: THEN-003
          statement: 模型先判断业务目标、业务结果、范围、约束或失败规则是否变化；变化时判定为 REQUIREMENT_CHANGE 或 NEW_REQUIREMENT
        - id: THEN-004
          statement: 业务承诺不变但场景、CHK、AST、验证责任或验证方式变化时判定为 SPEC_CHANGE；定义均不变而只改代码、测试或环境时判定为 IMPLEMENTATION_ONLY；都未变化时判定为 NO_REQUIREMENT_CHANGE
        - id: THEN-005
          statement: 模型根据变化判断选择 REQ、SPEC、IMPLEMENTATION 或 ACCEPTANCE 中唯一的当前责任节点，并输出一个有依据的最小下一步及其负责人或阻塞原因
      delivery_surfaces: [skill]
    - id: SCN-003
      title: 高影响歧义进入澄清而非猜测
      business_result: 会改变交付结果的歧义被澄清，低风险或可由工程事实确定的问题不阻塞推进。
      given:
        - 输入包含会改变业务结果、范围、验收语义或不可逆风险的歧义
      when: 模型准备选择节点或执行动作
      then:
        - id: THEN-006
          statement: 对高影响歧义调用 dc-grilling 并只提出当前必要问题
        - id: THEN-007
          statement: 不把验收执行、证据审查或最终验收裁决委托给 dc-grilling
      delivery_surfaces: [skill]
    - id: SCN-004
      title: 结构化事件继续可校验和可渲染
      business_result: 正式交付事件能够生成可读评论和可解析机器块，但不触发自动路由。
      given:
        - 模型已决定需要发布 REQ、SPEC、IMPLEMENTATION 或 ACCEPTANCE 事件
      when: 调用事件准备工具
      then:
        - id: THEN-008
          statement: 工具校验事件结构并生成包含人类摘要和 YAML 机器块的评论
        - id: THEN-009
          statement: 工具不根据事件时间、最新评论或 next_actions 自动选择后续节点
      delivery_surfaces: [skill]
    - id: SCN-005
      title: 审核页不展示场景优先级
      business_result: 审核页展示验收场景时不出现无业务含义的优先级或“未设”占位。
      given:
        - 当前 SPEC 包含验收场景
      when: 用户查看审核工作台中的场景
      then:
        - id: THEN-010
          statement: 场景区域只展示场景 ID 和验收状态，不展示优先级或“未设”占位
      delivery_surfaces: [web]
  open_questions: []
  confirmation: null
```
