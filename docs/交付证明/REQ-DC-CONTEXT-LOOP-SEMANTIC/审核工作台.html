需求定义

Deep Crew 技能循环应将 intake 获取的完整原始评论时间线、本地代码与知识文件、以及用户最新消息交给模型，由模型总结当前上下文、判断需求变化、选择交付节点并决定下一步；脚本不再自动归约状态或路由节点；验收场景与验收矩阵作为一份完整 SPEC 只进行一次人工确认。

纳入范围

  • dc-context-loop 的上下文理解与跨节点路由契约
  • dc-issue-intake 原始时间线作为模型输入
  • dc-grilling 的触发边界与验收职责边界
  • SCN 与 CHK/AST 合并为一次完整 SPEC 人工确认
  • 结构化事件校验、评论渲染、相关测试和评估

排除范围

  • 其他独立 deep-crew 技能副本的同步改造
  • Multica 平台本身的 API 或数据模型改造
