# Design Tree 内部判断

Design Tree 是 Agent 在当前对话中的临时思考工具，用于决定先查什么、现在问什么、何时停止。它不对应 Issue 节点、机器事件、稳定 ID 或评论格式。

## 问题进入条件

```text
可从 Issue、仓库或环境查到 → 先查事实，不问用户
前置决策尚未明确 → 暂不询问依赖问题
答案会改变当前交付结果 → 当前问题
只影响措辞、排版或未来优化 → 不问或延期
```

## 尺度判断

```text
歧义不改变当前结果 → 不讨论
歧义可逆且低风险 → 说明假设后继续
歧义会改变结果且无法安全假设 → 询问用户
```

一轮默认只问 1-3 个当前能回答的高影响问题。问题之间存在依赖时，先问上游问题。不要把整棵树一次展示给用户。

## 回答处理

把用户回答直接合入当前共享理解，并重新判断：

- 当前动作是否已经可以安全执行；
- 是否还有会改变结果的阻塞问题；
- 剩余内容是否可以作为非阻塞假设或延期问题。

推荐不等于回答。用户没有授权时，不得把 Agent 的建议当成确认决策。

## 收束

一旦当前动作可以安全执行就停止追问，输出将写入目标节点的简短摘要。讨论无需命名、编号、分轮或发布；下一次出现新歧义时，直接基于届时的完整上下文继续讨论。
