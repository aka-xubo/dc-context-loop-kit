# Testing Public Behavior

## 公开代码接口

开发实现中的单元检查优先通过调用者实际使用的代码级入口验证行为，例如应用服务、导出函数、领域行为或用例入口。默认测试先行时也使用同一公开接口；这里的公开接口不等同于 HTTP 接口。

好的测试：

- 建立已确认场景要求的前置条件。
- 执行真实业务 Action。
- 断言调用者可观察的结果和不变量。
- 在内部重命名或重构后仍然成立。

不充分的测试：

- 只断言方法没有抛错。
- 只断言内部 Mock 被调用。
- 测试私有方法或内部调用顺序。
- 通过直接写入预期结果绕过真实 Action。

## 断言映射

每个测试必须保存从矩阵断言到测试断言的追踪：

```text
AST-001 创建退款单
→ RefundServiceTest.apply_success 中的退款单数量与字段断言

AST-002 订单状态更新
→ RefundServiceTest.apply_success 中的订单状态断言
```

测试通过但缺少任何必需断言时，最终证据审查为 `INSUFFICIENT`。
